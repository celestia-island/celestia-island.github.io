# Fuuka

Запускайте GitHub Actions на собственных машинах

Плоскость исполнения self-hosted CI: она забирает ожидающие в очереди задачи GitHub Actions на ваших собственных узлах, выполняет каждый шаг в изолированной контейнерной песочнице, собирает артефакты и разворачивает собранные бинарные файлы на целевые хосты.
