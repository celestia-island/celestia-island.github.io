# Cherino

Изолированные контейнеры за одним трейтом

Набор инструментов контейнерной песочницы: единый трейт ContainerOps с Docker в качестве основного бэкенда, rootless youki как запасной вариант и экспериментальные CLI-бэкенды — встроенные профили безопасности, AppArmor, seccomp и политика egress.
